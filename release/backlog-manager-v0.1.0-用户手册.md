# Backlog Manager 用户手册

**版本：** v0.1.0
**发布日期：** 2026-03-12

---

## 产品简介

Backlog Manager 是一款基于终端界面（TUI）的轻量级任务管理工具，适合在命令行环境下快速管理待办事项。它以 SQLite 作为本地存储，无需网络连接，启动即用。

**v0.1.0 新增功能：**

- **删除二次确认**：防止误删，每次删除前弹出确认对话框
- **回收站**：被删除的条目自动进入回收站，保留 180 天，期间可随时恢复

---

## 安装和启动

### 环境要求

- Python 3.8 及以上版本
- 支持 Linux / macOS / Windows（需终端支持）

### 安装依赖

在项目根目录执行：

```bash
pip install -r requirements.txt
```

### 启动应用

```bash
python src/app.py
```

启动后将进入全屏终端界面，即可开始使用。

## 功能说明

### 主界面

启动后显示主界面，列出所有活跃的 Backlog 条目，包含以下列：

- **ID**：条目唯一编号
- **Title**：条目标题
- **Status**：当前状态（如 Todo、In Progress、Done）
- **Priority**：优先级（High / Medium / Low）
- **Category**：所属分类

使用方向键（`↑` / `↓`）或 `j` / `k` 在列表中移动选中行。

---

### 添加条目

按 `a` 键打开添加表单，填写以下信息后按 `Enter` 保存：

- 标题（必填）
- 描述（选填）
- 状态
- 优先级
- 分类

---

### 编辑条目

选中一个条目后，按 `e` 键打开编辑表单，修改后保存。

---

### 删除条目（含二次确认）

选中一个条目后，按 `d` 键触发删除操作。

系统将弹出**确认对话框**，显示被删除条目的标题及提示：

```
Move to Trash?
The item will be moved to trash and can be restored within 180 days.

[y] Yes   [n] No
```

- 按 `y` 或 `Enter`：确认删除，条目移入回收站
- 按 `n` 或 `Esc`：取消操作，条目保留

> 注意：删除后的条目不会立刻消失，而是进入回收站，可在 180 天内恢复。

---

### 搜索条目

按 `/` 键打开搜索框，输入关键字后按 `Enter` 过滤显示符合条件的条目。

---

### 回收站

#### 打开回收站

在主界面按 `t` 键打开回收站视图，显示所有已删除但尚未过期的条目，包含以下列：

- **ID**：条目编号
- **Title**：条目标题
- **Category**：所属分类
- **Deleted At**：删除时间
- **Expires At**：过期时间（删除后 180 天）

使用方向键选中条目后，可执行以下操作：

#### 恢复条目

选中回收站中的条目，按 `r` 键将其恢复到主列表。

恢复成功后：
- 该条目从回收站移除
- 该条目重新出现在主界面列表中

#### 永久删除条目

选中回收站中的条目，按 `x` 键触发永久删除。

系统将弹出二次确认对话框：

```
Delete Forever?
This action cannot be undone.

[y] Yes   [n] No
```

- 按 `y` 或 `Enter`：确认永久删除，条目从系统中彻底移除，**不可恢复**
- 按 `n` 或 `Esc`：取消操作

#### 关闭回收站

按 `Esc` 键返回主界面。

---

### 自动清理过期条目

每次启动 Backlog Manager 时，系统自动清理回收站中已超过 180 天的条目，无需手动操作。过期条目一旦被清理，将无法恢复。

## 注意事项

1. **删除操作均为软删除**：按 `d` 键后，条目不会立即消失，而是进入回收站，保留 180 天。如需彻底删除，请在回收站中使用永久删除（`x` 键）。

2. **过期条目不可恢复**：回收站中的条目在删除后 180 天将自动被系统清除，清除后无法通过任何方式恢复，请及时处理重要条目。

3. **永久删除不可撤销**：在回收站中按 `x` 键并确认后，条目将从系统中彻底删除，无法恢复。操作前请确认。

4. **数据库自动升级**：如果您是从旧版本升级，应用首次启动时会自动完成数据库结构升级，无需手动操作，现有数据不受影响。

5. **时间基于本地时间**：删除时间和过期时间均以运行设备的本地时间为准，跨时区使用时 180 天的计算可能存在轻微偏差。
