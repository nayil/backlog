## 1. 产品简介

Backlog Manager 是一款基于终端的任务管理工具（TUI），帮助你在命令行中高效管理工作任务（Backlog 条目）。支持任务的添加、编辑、删除、状态流转和优先级管理，所有数据持久化存储在本地 SQLite 数据库中。

---

## 2. 安装与启动

### 环境要求

- Python 3.10+
- 依赖库：`textual`、`sqlite3`（内置）

### 安装依赖

```bash
pip install textual
```

### 启动程序

```bash
cd <项目根目录>
python -m src.app
```

或在 worktree 环境中：

```bash
cd .worktrees/v0.2.0
python -m src.app
```

## 3. 界面说明

启动后进入主界面，主要区域如下：

| 区域 | 说明 |
|------|------|
| **标题栏** | 显示应用名称 "Backlog Manager" |
| **任务列表** | 以表格形式展示所有任务条目 |
| **底部工具栏** | 显示常用快捷键提示 |

### 任务列表列说明

| 列名 | 说明 |
|------|------|
| **ID** | 任务唯一编号 |
| **Title** | 任务标题 |
| **Status** | 当前状态（TODO / IN PROGRESS / DONE） |
| **Category** | 任务分类（可选） |
| **Priority** | 优先级（LOW / MEDIUM / HIGH） |
| **Age** | 自创建日期起经过的天数（格式：`Nd`，如 `3d` 表示 3 天前创建；`0d` 表示今日创建；`-` 表示无创建日期记录） |

## 4. 功能使用说明

### 4.1 添加任务

按 `a` 键打开任务添加表单，填写以下信息：

- **Title**（必填）：任务标题
- **Description**（可选）：任务描述
- **Category**（可选）：任务分类
- **Priority**：优先级，可选 LOW / MEDIUM / HIGH（默认 MEDIUM）
- **Status**：初始状态，可选 TODO / IN PROGRESS / DONE（默认 TODO）

填写完成后按确认按钮或 `Enter` 保存，按 `Escape` 取消。

### 4.2 编辑任务

在任务列表中选中目标任务，按 `e` 键打开编辑表单。

- 可修改任务的所有字段，包括状态。
- 状态变更遵循合法转换规则（见 [注意事项](#6-注意事项)）。
- 修改完成后保存，变更立即生效并反映在列表中。

### 4.3 删除任务

在任务列表中选中目标任务，按 `d` 键，确认后删除该任务。操作不可撤销，请谨慎操作。

### 4.4 查看任务详情

在任务列表中选中目标任务，按 `Enter` 键查看该任务的完整详情，包括描述内容、创建时间等。

### 4.5 状态管理

任务状态支持以下合法转换路径：

```
TODO → IN PROGRESS → DONE
                   ↓
                  TODO
DONE → IN PROGRESS
```

> 不支持从 DONE 直接转换为 TODO，如需此操作请先转为 IN PROGRESS，再转为 TODO。

### 4.6 查看历史版本列表（v0.2.0 新增）

按 `v` 键弹出版本历史弹窗，展示当前 `release/` 目录下所有已发布的历史版本号，按版本号降序排列（最新版本在最前）。

- 按 `Escape` 关闭版本历史弹窗。
- 如 `release/` 目录不存在或无版本文件，将显示 `(no releases found)` 提示。

### 4.7 查看帮助

按 `?` 键打开帮助界面，查看所有可用快捷键说明。

## 6. 注意事项

1. **数据存储**：所有任务数据保存在本地 SQLite 文件中（默认路径为项目目录下的 `backlog.db`），请勿手动删除或修改该文件。

2. **状态转换限制**：状态变更遵循预定义的合法转换规则，不支持所有状态之间的自由切换。如需从 DONE 回到 TODO，需先转为 IN PROGRESS。

3. **Age 列精度**：Age 列以"天数"为单位，今日创建的任务显示 `0d`。天数计算基于本地时间，跨时区使用时可能存在 ±1 天偏差。

4. **版本列表来源**：历史版本列表由程序自动扫描 `release/` 目录下的文件名生成，仅识别格式为 `v主版本.次版本.修订号`（如 `v0.2.0`）的版本号。

5. **终端兼容性**：建议在支持 256 色或 True Color 的现代终端（如 iTerm2、Windows Terminal、GNOME Terminal）中运行，以获得最佳显示效果。

## 7. 版本信息

### v0.2.0（2026-03-12）当前版本

**主要变更：**

- **Bug Fix**：修复任务状态变更保存后不生效的问题（编辑任务时修改状态，保存后状态现在可正确持久化）
- **新功能**：主列表新增 **Age 列**，展示每条任务自创建日期起经过的天数
- **新功能**：新增 **历史版本列表**（按 `v` 键），弹窗展示 `release/` 目录下所有历史版本号
- **优化**：帮助界面（`?`）同步更新，新增 `v` 键功能说明

### v0.1.0（初始版本）

**主要功能：**

- 基于 Textual TUI 框架的终端任务管理工具
- 支持任务的添加、编辑、删除和详情查看
- 支持任务状态管理（TODO / IN PROGRESS / DONE）及合法状态转换
- 支持优先级管理（LOW / MEDIUM / HIGH）
- 支持任务分类（Category）
- 数据持久化到本地 SQLite 数据库
- 快捷键帮助界面（`?` 键）
