## 产品简介

Backlog Manager 是一款基于终端界面（TUI）的轻量级任务管理工具，适合在命令行环境下快速管理待办事项。它以 SQLite 作为本地存储，无需网络连接，启动即用。

**v0.2.0 主要功能：**

- **添加 / 编辑 / 删除条目**，操作简单，支持二次确认防误删
- **状态管理**：在 Todo、In Progress、Done 三种状态间切换
- **关键字搜索与分类过滤**：按关键字、状态或分类快速定位条目
- **主列表与回收站翻页**：条目过多时支持分页浏览，每页 20 条
- **回收站**：删除条目自动进入回收站，保留 180 天，可随时恢复
- **回收站搜索**：在回收站内按关键字搜索已删除条目
- **删除时间精确到秒**：回收站显示精确到秒的删除时间
- **帮助界面**：随时按 `?` 查看快捷键说明

## 安装和启动

### 环境要求

- Python 3.8 及以上版本
- 支持 Linux / macOS / Windows（需终端支持）

### 安装依赖

在项目根目录执行：

```bash
pip install -r requirements.txt
```

### 启动应用

```bash
python src/app.py
# 或
python -m src.app
```

启动后将进入全屏终端界面，数据库会在首次启动时自动创建，无需额外配置。

## 主界面说明

启动后显示主界面，包含以下区域：

- **顶部过滤栏**：用于按状态（Status）和分类（Category）筛选条目的下拉选择器
- **条目列表**：显示所有活跃 Backlog 条目，包含以下列：
  - **ID**：条目唯一编号
  - **Title**：条目标题
  - **Status**：当前状态（Todo / In Progress / Done）
  - **Priority**：优先级（Low / Medium / High）
  - **Category**：所属分类
  - **Created At**：创建时间
- **底部状态栏**：显示当前过滤结果总数、页码信息及可用快捷键提示

> 回收站中的条目不显示在主列表中。按 `t` 打开回收站视图管理已删除条目。

## 功能说明

### 浏览条目

使用 **方向键（`↑` / `↓`）** 在列表中移动选中行。

---

### 添加条目

按 `a` 键打开**添加条目**表单，填写以下信息后按 **Enter** 保存：

- **标题**（必填）
- **状态**：Todo / In Progress / Done
- **优先级**：Low / Medium / High
- **分类**：自定义文本标签，用于分组管理

保存后，新条目立即出现在主列表中。

---

### 编辑条目

选中一个条目后，按 `e` 键打开**编辑条目**表单。

表单将预填当前条目信息，修改任意字段后确认保存即可。

---

### 删除条目

选中一个条目后，按 `d` 键触发删除操作。

系统将弹出**确认对话框**：

```
Move to Trash?
The item will be moved to trash and can be restored within 180 days.

[y] Yes   [n] No
```

- 按 `y` 或 `Enter`：确认删除，条目移入回收站
- 按 `n` 或 `Esc`：取消操作，条目保留

> 删除后的条目不会立刻消失，而是进入回收站，可在 180 天内随时恢复。

---

### 切换状态

选中一个条目后，按 `s` 键快速切换状态，循环顺序如下：

```
Todo → In Progress → Done → In Progress → ...
```

> 注意：条目到达 Done 状态后，按 `s` 会回到 In Progress，而非 Todo。如需设回 Todo，请使用编辑表单（`e`）。

---

### 搜索与过滤

**关键字搜索（主列表）：**

按 `/` 键打开搜索框，输入关键字后按 `Enter` 过滤，匹配 title 和 description 字段。按 `Esc` 清除过滤，返回完整列表。

**状态和分类过滤：**

使用主界面顶部的下拉选择器，按状态（All / Todo / In Progress / Done）或分类筛选条目，选择后列表即时更新。

> 切换过滤条件时，页码自动重置到第 1 页。

---

### 主列表翻页

当条目较多时，主列表自动分页显示（每页 20 条）。底部状态栏显示当前页码和总页数：

```
Total: 45 | Page 2/3  [N]ext [P]rev
```

| 按键 | 功能 |
|------|------|
| `n` | 下一页 |
| `p` | 上一页 |

> 切换过滤条件或搜索关键字后，页码自动重置到第 1 页。

---

### 回收站

#### 打开回收站

在主界面按 `t` 键打开**回收站**视图，显示所有已删除但尚未过期的条目：

| 列 | 说明 |
|----|------|
| ID | 条目编号 |
| Title | 条目标题 |
| Category | 所属分类 |
| Deleted At | 删除时间（精确到秒，格式：YYYY-MM-DD HH:MM:SS） |
| Expires At | 过期时间（删除后 180 天） |

#### 回收站翻页

回收站条目较多时同样支持分页浏览（每页 20 条），底部提示栏显示页码信息：

```
[R] Restore | [X] Delete Forever | [/] Search | [Esc] Close | Page 1/2 [N]ext [P]rev
```

| 按键 | 功能 |
|------|------|
| `n` | 下一页 |
| `p` | 上一页 |

#### 回收站搜索

在回收站界面按 `/` 键打开搜索弹窗，输入关键字可按 title 和 description 过滤回收站条目。

搜索激活后，底部提示栏显示当前关键字（如 `Filter: "login"`）；清除搜索后显示 `Filter cleared`。

> 搜索条件变更时，页码自动重置到第 1 页。

#### 恢复条目

在回收站中选中条目后，按 `r` 键将其**恢复**到主列表。

恢复成功后：
- 该条目从回收站移除
- 该条目重新出现在主界面列表中

#### 永久删除条目

在回收站中选中条目后，按 `x` 键触发**永久删除**。

系统将弹出二次确认对话框：

```
Delete Forever?
This action cannot be undone.

[y] Yes   [n] No
```

- 按 `y` 或 `Enter`：确认永久删除，条目从系统中彻底移除，**不可恢复**
- 按 `n` 或 `Esc`：取消操作

#### 关闭回收站

按 `Esc` 键返回主界面。

---

### 查看帮助

在主界面按 `?` 键打开**帮助界面**，显示所有可用快捷键和功能说明。

按 `Esc` 或 `q` 关闭帮助界面（不退出应用）。

---

### 退出应用

在**主界面**按 `q` 键退出应用。

## 注意事项

1. **删除操作均为软删除**：按 `d` 键后，条目不会立即消失，而是进入回收站，保留 180 天。如需彻底删除，请在回收站中使用永久删除（`x` 键）。

2. **过期条目不可恢复**：回收站中的条目在删除后 180 天将自动被系统清除，清除后无法通过任何方式恢复，请及时处理重要条目。

3. **永久删除不可撤销**：在回收站中按 `x` 键并确认后，条目将从系统中彻底删除，无法恢复。操作前请确认。

4. **翻页快捷键的适用范围**：`n` / `p` 翻页键在主列表和回收站界面均有效，但在编辑、添加等弹窗内无效，关闭弹窗后恢复。

5. **搜索与翻页联动**：切换搜索关键字或过滤条件时，页码自动重置到第 1 页，避免出现空白页。

6. **删除时间精度**：回收站显示的删除时间精确到秒（格式：`YYYY-MM-DD HH:MM:SS`），方便区分同分钟内的多次操作。

7. **数据库自动升级**：如果您是从旧版本升级，应用首次启动时会自动完成数据库结构升级，无需手动操作，现有数据不受影响。

8. **时间基于本地时间**：删除时间和过期时间均以运行设备的本地时间为准，跨时区使用时 180 天的计算可能存在轻微偏差。
